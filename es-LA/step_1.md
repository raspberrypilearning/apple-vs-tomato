## Lo que harás

![La imagen muestra una interfaz de aprendizaje automático de "Teachable Machine" donde se está entrenado un modelo para clasificar imágenes de manzanas y tomates. A la izquierda, hay dos secciones etiquetadas: "Manzana" con 64 muestras de imágenes y "Tomate" con 24 muestra de imágenes. Cada sección muestra una imagen miniatura, thumbnail en inglés, correspondiente a cada clase (manzanas y tomates) y tiene opciones para subir imágenes a través de la cámara web o botón Subir. A la derecha, hay una sección de "Vista previa" que muestra el resultado de la clasificación del modelo a partir de una toma de la cámara web, donde una mano está sosteniendo un tomate. Debajo, la sección "Salida" muestra los resultados de la clasificación: 16% para "Manzana" y 84% para "Tomate", indicando que el modelo ha identificado el objeto como un tomate.](images/wywm.png)

Entrena un modelo de aprendizaje automático a detectar si estás sosteniendo una manzana o un tomate. Luego, mejora el clasificador utilizando datos de entrenamiento más diversos.

Necesitarás una **cámara web**, una **manzana roja**, una **manzana verde** y un **tomate rojo**.

Necesitarás poder descargar y guardar archivos en tu computadora.

## title: ¿Dónde se almacenan mis imágenes?

- Este proyecto utiliza una tecnología llamada 'aprendizaje automático', 'machine learning' en inglés. Los sistemas de aprendizaje automático son entrenados utilizando una gran cantidad de información.
- Este proyecto no requiere que crees una cuenta o inicies sesión. Para este proyecto, las imágenes de ejemplo que uses para crear el modelo solo se almacenan temporalmente en tu navegador (solo en tu computadora).
- No se envía ninguna imagen de tu cámara web a este sitio web ni a ningún otro sitio web.
