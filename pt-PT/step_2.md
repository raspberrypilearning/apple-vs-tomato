### Preparar o modelo

Abre [Teachable Machine](https://rpf.io/tm){:target="_blank"}.

Muda o nome `Classe 1` para `Maçã`

Muda o nome `Classe 2` para `Tomate`.

### Descarregar imagens de exemplo

Descarrega a [pasta que contém as imagens iniciais](https://rpf.io/tams){:target="_blank"}.

A pasta vai descarregar como um ficheiro zip.

Descompactar a pasta.

## title: How to unzip

**Microsoft Windows**

- Abre a tua pasta das 'Transferências'.
- Clica com o botão direito do rato no ficheiro zip e seleciona **Extrair todos**.

**ChromeOS**

- Abre Ficheiros.
- Clica duas vezes no ficheiro zip.
- À esquerda, vais encontrar o ficheiro zip.
- Arrasta e solta os ficheiros/pastas para a nova pasta à tua escolha.

**macOS**

- Abre a tua pasta das 'Transferências'.
- Clica duas vezes no ficheiro zip.
- Uma nova pasta vai ser criada que contém os ficheiros/pastas descompactados.

**Linux**

- Abre a tua pasta das 'Transferências'.
- Clica com o botão do lado direito do rato no ficheiro zip e seleciona **Extrair aqui**.

### Adicionar imagens de exemplo

Carrega as imagens da **maçã** verde para a classe 'Maçã'.

Carrega as imagens do **tomate** vermelho para a classe 'Tomate'.
