## O que vais fazer

![A imagem mostra a interface de uma machine learning do "Teachable Machine", onde um modelo é treinado para classificar imagens de maçãs e tomates. À esquerda, há duas secções rotuladas: "Maçã" com 64 exemplos de imagens e "Tomate" com 24 exemplos de imagens. Cada secção mostra miniaturas de imagens correspondentes a cada classe (maçãs e tomates) e tem as opções para carregar imagens via webcam ou com botões de carregamento. À direita, há uma secção "Pré-visualização" que mostra o resultado da classificação do modelo de uma entrada da webcam, onde uma mão segura um tomate. Em baixo, a secção "Saída" exibe os resultados da classificação: 16% para "Maçã" e 84% para "Tomate", o que indica que o modelo identificou que o objeto é um tomate.](images/wywm.png)

Treina um modelo de machine learning para detetar se estás a segurar uma maçã ou um tomate. Em seguida, melhora a classificação ao usar dados de treino diversos.

Vais precisar de uma **webcam**, uma **maçã vermelha**, uma **maçã verde** e um **tomate vermelho**.

Vais precisar de conseguir descarregar e salvar ficheiros para o teu computador.

## title: Onde estão guardadas as minhas imagens?

- Este projeto usa uma tecnologia chamada 'machine learning'. Os sistemas de machine learning são treinados com uma grande quantidade de dados.
- Este projeto não exige que cries uma conta ou faças login. Para este projeto, as imagens de exemplo que usas para fazer o modelo são armazenados temporariamente no teu navegador (apenas na tua máquina).
- Nenhuma imagem da tua webcam é enviada para este site ou qualquer outro.
